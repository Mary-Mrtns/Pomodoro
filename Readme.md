#  Pomodoro Timer

Um site de temporizador Pomodoro, feito em HTML, CSS e JavaScript puros, com uma estética cozy e pixel art.

>  **Projeto em construção** — sendo desenvolvido aos poucos, com commits frequentes conforme as funcionalidades vão sendo criadas.

##  Sobre o projeto

A técnica Pomodoro ajuda a organizar o tempo de estudo/trabalho em ciclos de foco e descanso. Este projeto é uma versão própria desse timer, sendo construída do zero como prática de HTML, CSS e JavaScript.
